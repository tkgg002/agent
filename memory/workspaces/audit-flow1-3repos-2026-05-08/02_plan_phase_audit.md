# Plan — Audit 3 Repo + Flow 1

## English

1. Establish the audit workspace and record the exact scope, constraints, and expected evidence.
2. Inspect the current state of the three repositories:
   - git status / branch / recent commits
   - available tests and build commands
   - runtime and startup logs when present
3. Re-check Flow 1 on CMS by combining:
   - existing workspace documentation
   - live logs / endpoints
   - frontend wizard implementation and backend route contract
4. Synthesize findings into:
   - per-repo health summary
   - Flow 1 blocker summary
   - recommended next action order
5. Append progress, validation, and status files before final reporting.

## Tiếng Việt

1. Khởi tạo workspace audit và ghi lại chính xác scope, ràng buộc, và loại chứng cứ cần thu thập.
2. Kiểm tra hiện trạng của 3 repo:
   - git status / branch / commit gần nhất
   - build/test khả dụng
   - log runtime và startup nếu có
3. Kiểm tra lại Flow 1 trên CMS bằng cách kết hợp:
   - tài liệu workspace đã có
   - logs / endpoint đang chạy
   - wizard FE và contract route phía backend
4. Tổng hợp findings thành:
   - bảng health cho từng repo
   - tóm tắt blocker của Flow 1
   - thứ tự hành động nên làm tiếp
5. Append progress, validation, status trước khi chốt báo cáo.
