# Yêu cầu: Hiển thị source count, dest count trên FE modal tab "Phiên chưa xử lý"

## 1. Mô tả yêu cầu
Hiển thị thêm thông tin `source count` và `dest count` trên Modal đối soát của Frontend (FE) tại tab "Phiên chưa xử lý" (Unprocessed Sessions).

## 2. Phạm vi ảnh hưởng
- Dự án Frontend: `cdc-cms-web`
- Component hiển thị Modal đối soát chi tiết hoặc danh sách phiên chưa xử lý.
- Dữ liệu API trả về cần có chứa `source count` và `dest count`.
