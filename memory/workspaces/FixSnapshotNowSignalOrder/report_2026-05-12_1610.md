# Report — Snapshot Now không chạy: BSON field-order race condition (2026-05-12 16:10 ICT)

## TL;DR
**Root cause**: Worker dùng `bson.M{}` (map vô thứ tự) để build Debezium signal doc. Go map iteration
order ngẫu nhiên → MongoDB persist field theo thứ tự ngẫu nhiên → khi field `data` đứng trước `type`
trong BSON wire payload, Debezium MongoDB SignalProcessor parse nhầm và DROP signal với log
`WARN Signal '<id>' has been received but the type '<json>' is not recognized`. Snapshot Now thành công
~50% (lúc Go map random ra `type` trước), thất bại ~50% (lúc random ra `data` trước).

**File:line**: `centralized-data-service/internal/service/debezium_signal.go:112-115`.

**Fix proposed (chưa apply)**: Đổi `bson.M{}` thành `bson.D{}` (slice ordered). Chi tiết tại
`agent/memory/workspaces/FixSnapshotNowSignalOrder/09_solution_proposed.md`.
