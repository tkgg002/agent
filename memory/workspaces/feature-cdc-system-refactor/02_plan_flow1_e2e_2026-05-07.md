## 4. Phase 2 — Fix root cause stuck pending (max worker-lane)

### Investigation
- Đọc `centralized-data-service/internal/service/provisioning_orchestrator.go` đầy đủ (236 line đã grep)
- Verify path nào set `provisioning_state='active'` mà không qua `Advance()` state machine
- Check migration 047 backfill `provisioned` state — có nhầm map sang `active` không?
- Check legacy admin endpoint nào set state machine bypass

### Hypothesis
1. **H1**: Có legacy admin endpoint set `provisioning_state='active'` direct (không qua state machine). Bug: should fire `Advance()` thay vì raw UPDATE.
2. **H2**: Migration 047 backfill `provisioned` map sai sang `active` cho 4 source mới (33,34,35,37 timestamp ~2026-04-XX gần migration 047 deploy).
3. **H3**: ProvisioningOrchestrator.Advance gọi nhưng publish fail silently — handler không fire → ddl_status stuck. Cần grep `o.nats.Publish` return path + log.

### Action plan
- max read full `provisioning_orchestrator.go` (~236 line) + `internal/admin/source_register.go` + `internal/admin/server.go` route table
- Check if exists endpoint set state direct (grep `provisioning_state\s*=\s*'active'` SQL)
- Test fix: thêm one-shot SQL/CLI re-fire `cdc.cmd.shadow.bind` cho 4 stuck source → verify ddl_status flip

### Fix candidates
- **Fix A (idempotent SQL re-fire)**: tạo `deployments/sql/cdc/refire_stuck_shadow_bind.sql` để publish `cdc.cmd.shadow.bind` cho stuck rows (qua NATS pub binary từ shell).
- **Fix B (orchestrator code)**: nếu H3 đúng → wrap `o.nats.Publish` với retry + persist last_step_error. File `provisioning_orchestrator.go:236`.
- **Fix C (one-time CLI)**: viết tool `cmd/refire_stuck_bind/main.go` scan stuck rows + publish. Run once.

## 5. Phase 3 — Hardening

### 3.1 — Add `POST /api/v1/sources/test` (cms)
File mới: `cdc-cms-service/internal/api/source_test_handler.go`
Endpoint: `POST /api/v1/sources/test` body `{engine_type, locator}` → return `{ok:true, schema_introspect:{cols:[...]}}` hoặc `{ok:false, error:...}`.

Implementation:
- PostgreSQL: `pgx.Connect(dsn).Ping()` + `SELECT column_name,data_type FROM information_schema.columns WHERE table_schema=$1 AND table_name=$2`
- MongoDB: `mongo.Connect().Database(db).Collection(coll).Stats()` + sample 1 doc
- MariaDB: `mysql.Open(dsn).Ping()` + `DESCRIBE <db>.<table>`

x2 lane.
