## Lesson cần ghi (sẽ append vào `agent/memory/global/lessons.md`)

**Global Pattern [A claims aggregate metric M=N derived from loop variable in source S]** → Pitfall: log chỉ in **tổng cuối** mà thiếu **bằng chứng vòng lặp** (iteration count). B đọc code thấy `+=` rồi tin tổng đúng = báo cáo láo vì không có observable runtime.

**Đúng**: log line nào claim "đã chạy chunked / batched / iterated" PHẢI có field `iterations` (hoặc `batches`, `pages`) bên cạnh `rows_affected`. Một metric đơn lẻ (rows=130) không phân biệt được "1 UPDATE 130 rows" vs "13 UPDATE 10 rows" — chính là root cause khiến user nghi báo cáo láo.

**Anti-pattern**: claim "chunked path đã chạy" chỉ dựa trên tên log message `(chunked)` thay vì observable iteration count. Tên log message không ràng buộc tới execution path thực tế (có thể fall-through, có thể nhánh khác).
