## 4. Backward compat strategy (key insight)

**Tracker keyed by basename**: `cdc_system.schema_migrations.version = strings.TrimSuffix(path.Base(relPath), ".sql")`.
- Anchor file giữ NGUYÊN tên (vd `013_table_registry_expected_fields.sql`) → tracker row khớp → SKIP trên cdc_dw bất kể content đã thay đổi.
- File bị DELETE → tracker row cũ tồn tại nhưng INERT (không có file match → runtime bỏ qua).
- Fresh DB chỉ thấy 30 file mới → apply 30 → tracker 30 rows.

**Idempotency layer (defense in depth)**: Mọi ADD COLUMN/INDEX dùng `IF NOT EXISTS`; CHECK constraint wrap trong DO block với pg_constraint check. Nếu sau này deploy lại từ trạng thái intermediate, mọi operation no-op.
