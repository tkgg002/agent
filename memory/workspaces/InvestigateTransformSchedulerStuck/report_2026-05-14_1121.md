## Root cause

`internal/server/worker_server.go:632-635` (trước fix):
```go
intervalDur := time.Duration(sched.IntervalMinutes) * time.Minute  // 60s
if sched.LastRunAt != nil && now.Sub(*sched.LastRunAt) < intervalDur {
    continue // Not due yet
}
```

`time.NewTicker(60*time.Second)` có jitter ~5-50ms từ Go runtime + GC pauses. DB poll roundtrip 20-100ms. Khi tick thực tế fire tại `T0 + 59.95s`:
- `now.Sub(*sched.LastRunAt) = 59.95s`
- Condition `59.95s < 60s` = TRUE → SKIP.
- Tick kế tại `T0 + 119.95s` → gap thực 120s.

Ticker channel buffer 1 nên không "bù" tick bị skip — chỉ drop, gây drift cộng dồn.

---

## Fix (Option A — slack tolerance)

**Patch** (`worker_server.go:627-637`):
```go
// Slack nuốt jitter của time.NewTicker (5-50ms) + DB roundtrip
// (~20-100ms). Không có slack: tick fires tại T0+59.95s đo
// được now.Sub(last_run)=59.95s < 60s → skip → gap thực 120s.
// Slack 5s giữ ≥91% utilization cho interval 1m, không ảnh
// hưởng interval lớn hơn.
const tickSlack = 5 * time.Second
intervalDur := time.Duration(sched.IntervalMinutes) * time.Minute
if sched.LastRunAt != nil && now.Sub(*sched.LastRunAt) < intervalDur-tickSlack {
    continue // Not due yet
}
```

**Tradeoff**:
- Interval 1m: effective minimum gap = 55s → 91.67% utilization.
- Interval 5m: 295s/300s = 98.3%.
- Interval 30m: 1795s/1800s = 99.7%.
- → Slack 5s acceptable cho tất cả interval ≥1m.

## Lesson cần ghi (sẽ append vào `agent/memory/global/lessons.md`)

**Global Pattern [A claims scheduler S ticks every interval D based on N=2-3 samples → B verifies done]** → Pitfall: extrapolation từ short window sau service restart bỏ qua drift tích lũy + off-by-epsilon. Đúng: verify timing claims qua **activity log DB query >=10 phút continuous window**, đo gap thực tế giữa các tick, accept claim chỉ khi 0% skip rate. Áp dụng cho mọi cron/poll/schedule pattern dùng `time.NewTicker` + DB-stored `last_run_at` gating.

**Anti-pattern**: report "tick đúng X giây" sau khi quan sát 2 mẫu đầu của restart (ticker chưa drift). 2 mẫu = noise floor, không signal.
