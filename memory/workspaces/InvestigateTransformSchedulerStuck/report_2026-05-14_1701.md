## 4. Deploy steps cho prod

Chỉ chạy nếu cluster DW mới hoàn toàn (chưa có role `cdc_worker/cms_service/cdc_readonly`):
```bash

     -v ON_ERROR_STOP=1 \
     -v worker_role='cdc_worker' -v worker_password="$CDC_WORKER_PASSWORD" \
     -v cms_role='cms_service'   -v cms_password="$CMS_SERVICE_PASSWORD" \
     -v ro_role='cdc_readonly'   -v ro_password="$CDC_READONLY_PASSWORD" \
     -v dw_database='cdc_dw' \
     -f migrations/cluster/001_roles.sql

psql -h dw-host -U postgres -d postgres \
     -v ON_ERROR_STOP=1 \
     -v admin_role='gpay_admin' \
     -f migrations/cluster/002_search_path.sql
```
