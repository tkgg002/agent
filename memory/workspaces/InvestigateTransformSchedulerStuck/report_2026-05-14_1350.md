## Lesson cần ghi (sẽ append vào `agent/memory/global/lessons.md`)

**Global Pattern [A claims taxonomy T from grep of literal string S in source]** → Pitfall: string S xuất hiện trong **2 contexts khác nhau** — (1) field `T` của struct được persist vào DB, (2) key `T` trong JSON payload publish ra channel. Chỉ context (1) mới thực sự là taxonomy. Grep blanket gắn tất cả vào T → báo cáo sai.

**Đúng**: verify taxonomy bằng query DB live (`SELECT DISTINCT field FROM table`) làm ground truth, KHÔNG dựa grep source code. Source code là phỏng đoán, DB là sự thật.

**Anti-pattern thực**: gắn `v2_bridge`, `sinkworker-hook`, `provisioning` thành "loại trigger" trong activity log — thực tế các string này chỉ là metadata trong NATS publish JSON, không bao giờ vào `cdc_activity_log.triggered_by`.

## Skills sử dụng

- Query DB live (`docker exec psql`) làm ground truth thay vì grep source.
- Phân biệt **struct field persist** vs **JSON payload pass-through**.
