## 4. Kiến trúc đề xuất (tóm tắt từ 02_plan)

3-layer migration taxonomy:

| Loại | Phạm vi | Lifecycle | User cần |
|---|---|---|---|
| **L1 Cluster bootstrap** | CREATE ROLE + GRANT cross-DB + ALTER ROLE | 1 lần / cluster | SUPERUSER / CREATEROLE |
| **L2 Database bootstrap** | CREATE DATABASE / EXTENSION | 1 lần / DB | CREATEDB / owner |
| **L3 Schema migration** | TABLE / INDEX / FUNCTION | Mỗi deploy | CREATE trên schema |

Phương án (chi tiết trong 09):
1. **Tách `cluster_bootstrap/`** khỏi `*.sql` top-level (NOT embed) — chứa 2 file SQL parameterize.
2. **Skip-list code-level** trong `internal/migrate/skip_list.go` cho 3 version cũ.
3. **Tracker mở rộng** column `applied_by` (additive ALTER) phân biệt nguồn.
4. **Bootstrap script DBA** `scripts/bootstrap_cms_db.sql` — INSERT 3 tracker row marker `cluster-bootstrap` + GRANT min cho `cms_user`.
5. **Legacy files** giữ nguyên body (idempotency tracker checksum), chỉ thêm comment DEPRECATED.
6. **Rotate password** 3 role qua secret manager (Phase 3).
