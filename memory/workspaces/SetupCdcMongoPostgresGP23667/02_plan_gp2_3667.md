# 02_plan_gp2_3667.md - Kế hoạch Thực thi Cao tầng (High-level Plan)

## Roadmap Triển khai Task GP2-3667

### Phase 1: Context & Database Model Discovery (Khảo sát Schema & Model)
- **Task 1.1:** Đọc mã nguồn và cấu hình MongoDB hiện tại của Transaction History.
- **Task 1.2:** Định nghĩa PostgreSQL Schema chuẩn cho `transaction_history` Master Table (mapping BSON types sang Postgres types: ISODate -> TIMESTAMPTZ, ObjectId -> VARCHAR/UUID, NumberLong -> BIGINT, Sub-documents -> JSONB/Flattened Columns).

### Phase 2: CMS Configuration Setup (Cấu hình trên cdc-cms-service)
- **Task 2.1:** Đăng ký / Kiểm tra System Connector cho Source MongoDB và Destination PostgreSQL.
- **Task 2.2:** Đăng ký Source Object (Collection `transaction_history`).
- **Task 2.3:** Thiết lập Shadow Table Binding & Master Table Binding (`master_transaction_history`).
- **Task 2.4:** Định nghĩa Mapping Rules chuyển đổi dữ liệu từ Shadow sang Master.

### Phase 3: Engine Pipeline Activation & Verification (Kích hoạt CDC Pipeline & Kiểm thử)
- **Task 3.1:** Kích hoạt Debezium MongoDB Connector & Snapshot Runner V2 (nếu có dữ liệu lịch sử cần backfill).
- **Task 3.2:** Chạy E2E flow test (Insert/Update trên MongoDB Mongo -> Change Streams -> Kafka -> Batch Buffer -> Transmuter -> Master PG).
- **Task 3.3:** Chạy Quality Gates (G1 - G8) và xuất báo cáo kết quả.
