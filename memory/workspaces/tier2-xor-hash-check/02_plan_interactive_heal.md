# Roadmap cao tầng (High-level Plan) - Luồng Chữa Lành Tương Tác

## 1. Các kỹ năng sẽ sử dụng (Skills to load)
* `write_file`, `replace_file_content` để cập nhật mã nguồn dự án.
* `run_command` để verify unit tests và build biên dịch.

## 2. Kế hoạch roadmap
* **Phase 1: Chuẩn bị tài liệu & Thiết kế** (Đang thực hiện - Chờ duyệt).
* **Phase 2: Thực thi Backend** (Mở rộng struct command ở gateway và logic lọc IDs, ngắt recon khi heal ở worker).
* **Phase 3: Thực thi Frontend** (Tích hợp modal hiển thị checkboxes chênh lệch và truyền cờ tương tác lên API).
* **Phase 4: Kiểm thử và nghiệm thu** (Chạy tests và thực hiện test manual trên UI).
