## Lưu ý còn lại (KHÔNG sửa trong session này — ngoài scope user request)

### A. `shadow_binding.ddl_status` stuck ở `pending`
Worker `HandleCreateDefaultColumns` (command_handler.go:451-455) chỉ update
`ddl_status='created'` khi `payload.SourceObjectID > 0`. Nhưng
`registry_handler_register.go:50-56` chỉ pass `RegistryID`:

```go
createCmd := commands.CreateDefaultColumnsCommand{
    RegistryID:      created.ID,        // ← chỉ có RegistryID
    TargetTable:     created.TargetTable,
    SourceTable:     created.SourceTable,
    PrimaryKeyField: created.PrimaryKeyField,
    PrimaryKeyType:  created.PrimaryKeyType,
}
```

Hậu quả: physical table đã tạo (qua `automator.EnsureShadowTable`), nhưng metadata
`shadow_binding.ddl_status` không được sync sang `created`. Cosmetic — không ảnh hưởng
flow user.

### B. `source_object_registry.profile_status = paused` cho new entry
Default của V2Sync. Không rõ có intentional không. Cần `provisioning_state` chuyển
từ `draft` → `shadow_pending` → `mapping_ready` qua orchestrator.
