## Root cause
3 dispatcher trong cms-service publish `CreateDefaultColumnsCommand` mà bỏ trống field
`ShadowSchema`. Worker (`centralized-data-service/internal/handler/command_handler.go:336-469`)
xử lý:
```go
schemaName := payload.ShadowSchema
if schemaName == "" { schemaName = "public" } // ← fallback gây dư bảng public
```
Hệ quả: bảng được tạo ở **cả** `shadow_<sourceDB>.<table>` (do `ShadowAutomator.EnsureShadowTable`
chạy sync trong cms) **và** `public.<table>` (do worker fallback). Bảng `public` không ai dùng.

### 1. New file: `cdc-cms-service/internal/naming/naming.go`
Mirror 1:1 pattern của worker (`centralized-data-service/internal/naming/naming.go`).

```go
package naming

import (
    "os"
    "sync"
)

const defaultShadowPrefix = "shadow_"

var (
    shadowOnce   sync.Once
    shadowPrefix string
)

func ShadowSchemaPrefix() string {
    shadowOnce.Do(func() {
        shadowPrefix = os.Getenv("CDC_SHADOW_SCHEMA_PREFIX")
        if shadowPrefix == "" {
            shadowPrefix = defaultShadowPrefix
        }
    })
    return shadowPrefix
}

func ShadowSchemaName(suffix string) string {
    return ShadowSchemaPrefix() + suffix
}
```
